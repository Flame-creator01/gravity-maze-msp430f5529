## 阅读建议

- **只想玩**：`overview.md` → `bringup.md` → `gameplay.md`。
- **要改代码**：再加 `architecture.md`、`state_machine.md`、`save_system.md`；改地图前读 `game_rules.md`。
- **要排查硬件**：`sensor_diagnostics.md` + `hardware_mapping.md`，再对照 `debug_log.md`。
- **要复用测试**：`validation.md` 看实际输出，`test_plan.md` 看待上板项目。

## 约定

- 所有文档结论区分“主机测试通过”与“实物验证”；没有实测数据的地方会明确写出，不把计划当作结果。
- 参数默认值以 `include/app_config.h` 为准，文档中给出的是出厂默认值；运行时可在 TUNE 调试台修改。
- 文档内的相对链接（如图片、代码路径）均以本目录为基准。
