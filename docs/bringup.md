# 首次上板与联调步骤

按下面的顺序一步步推进，每一步都先确认现象再进入下一步。导入编译见 [CCS 导入与编译](ccs_setup.md)。

## 第一轮：工程与下载

按 `ccs_setup.md` 导入并 Build。如果出现错误，优先保留完整的**首条 error 及其前后输出**，一次处理一个根因。无需先连接外部模块。

成功下载后运行到 `main`，确认能继续运行。注意：在断点暂停 MCU 期间，游戏和系统时基也会暂停，程序必须自由运行（F8 / Running）才能扫描按键与采样；连续性能验证同样要自由运行。调试器停机较长时间后，传感器与 MCU 时间不同步属于需考虑的调试条件。

在 CCS Expressions 添加 `g_debug`，它是 `volatile` 结构体，方便在暂停时观察：

| 字段 | 含义与正常预期 |
|---|---|
| `sensor_type` | 1=CMA3000，2=LIS3DH，0=未识别 |
| `raw_mg.x/y/z` | 标称 mg，平放时 Z 约 ±1000，倾斜会改变 X/Y |
| `accel_diag.raw_counts.x/y/z` | CMA3000为有符号8位原始计数；LIS3DH为解码后的12位HR计数 |
| `accel_diag.id` | CMA3000 REVID；LIS3DH WHO_AM_I（0x33），含义不能混用 |
| `accel_diag.ctrl / ctrl4` | CMA3000 CTRL应为0x94、ctrl4未用；LIS3DH应为0x47/0x88 |
| `accel_diag.status` | 状态寄存器；CMA3000 bit0置位即报告校验错误 |
| `accel_diag.bus_ok / sample_valid` | 最近操作未超时 / 最近读取成功产出样本；1不代表物理测量准确 |
| `valid_samples` | 每 20ms 尝试更新，收到有效数据后增长 |
| `calibration_samples` | S1 后先等待 1 秒，再逐渐增加到 64 |
| `calibration_failure` | 0无失败、1波动过大、2Z重力分量/姿态异常、3X/Y倾斜过大 |
| `calibration_span_x/y/z` | 本次64个样本的峰峰差，单位mg |
| `calibration_mean_mg.x/y/z` | 本次64个样本的均值，X/Y已按轴映射，单位mg |
| `offset_x/offset_y` | 校准时的水平偏置 |
| `filtered_x/filtered_y` | 运行状态的滤波数据 |
| `direction` | 0停止、1上、2下、3左、4右 |
| `state` | 1校准、2菜单、3运行、4暂停、5通关、6错误、7诊断 |
| `unlocked` | 已解锁关卡数（1～6），来自信息 Flash 进度 |
| `new_best` | 1=最近一次通关刷新了该关最佳纪录 |
| `save_ok` | 1=最近一次信息 Flash 保存成功；0=失败，游戏继续 |
| `error` | 0无错、1初始化失败、2读取失败或超时 |
| `lcd_ok` | 1=传输过程未超时；不代表屏幕物理显示已验证 |

## 第二轮：屏幕和按键

预期出现 `CALIBRATE`。若背光亮但没有内容，核对板卡类型、LCD 排线、`LCD_CONTRAST` 和 SPI 引脚；不能只凭背光判定驱动成功。显示倒置时先核对原厂初始化与页方向，不修改游戏坐标。

S1/P1.7，S2/P2.2，均低有效。如果按键不响应，暂停后观察 `P1IN` 的 BIT7 和 `P2IN` 的 BIT2，再判断是否为消抖逻辑问题。

短按在松开后才触发；建议按住约 0.1～0.3 秒再松开。长按约 0.8 秒会触发另一功能。按键已改为每 5ms 定时中断扫描、20ms 消抖、事件队列交给主循环，覆盖升级与复测步骤见下文“按键复测”。

## 第三轮：传感器与校准

进入诊断页或观察 `g_debug.raw_mg`，缓慢向四个方向倾斜。正常数据应平滑变化，不能长时间固定全零或满量程。

按 [传感器诊断与 Z 轴排查](sensor_diagnostics.md) 观察诊断页：左列mg，右列原始计数，第二行I/C/S为十六进制寄存器，B为通信超时状态。诊断页短按S1重新初始化，成功回校准，再长按S2回诊断。若显示 `SENSOR ERROR`，拍下整屏并短按S1重试。实物为SEEED V1.0，保留自动识别配置；不要仅凭TI板卡Rev编号更改型号。

平放板子后短按 S1，松手静置：`HANDS OFF 1 SEC` 等待 1 秒，随后 `KEEP STILL` 采集 64 个样本。合计约 2.3 秒或更长；采样由主循环调度，实际速度仍需上板测量。板子正面朝上平放在稳固桌面，USB 线保持松弛，避免线材拉扯。

失败时记录完整屏幕：`TOO MUCH MOTION` 为峰峰差超过120mg；`CHECK Z / POSTURE` 为Z轴均值绝对值不在600～1400mg；`BOARD NOT FLAT` 为X/Y均值绝对值超过600mg。DX/DY/DZ表示三个轴的峰峰差，Z为均值，单位mg。它们是检查结果，尚不能单独证明机械晃动或通信故障。继续长按S2查看诊断数据，校准流程与失败页细节见 [上板校准操作](#上板校准操作)。

## 第四轮：玩法与手感

校准通过后进入菜单。当前实现有 6 关，每关 1～4 个能量点 `o`，收集完出口才打开；`x` 为陷阱，踩到退回起点并罚时 3 秒。菜单显示 `LEVEL`、`BEST` 与 `PROGRESS`；未解锁关卡显示 `LOCKED`，通关当前关后自动解锁下一关（想自由选关把 `GAME_LEVEL_LOCK` 改为 0）。

方向：左右或上下反向时只改 `MOTION_X_SIGN`、`MOTION_Y_SIGN`；两个轴交换则改 `MOTION_SWAP_XY`。默认配置为 X 方向 `−1`、Y 方向 `1`（`SWAP_XY=0`）。修改后重新校准，并在有通道处确认左右。

移动速度由倾角决定（默认 190ms→90ms 每格，130mg 起触发）：先轻倾确认能逐格对准，再重倾确认能加速。**手感不合适优先用板载 TUNE 调试台**：菜单长按 S2 进诊断页，再长按 S2 进 TUNE；**转滚轮调当前参数**，S1/S2 短按切换参数，长按 S2 保存，长按 S1 不保存返回。若换向慢或回中后还在滑，把 `FILTER` 调到 3/4；若静止时小球抖，调到 1/4。滚轮是模拟拇指轮（P6.5/A5，P8.0 使能），若转向相反把 `WHEEL_INVERT` 改为 1。调试台实时显示当前倾角与计算出的步进间隔，选 `DEFAULT` 转一下滚轮可恢复默认。调参保存在 INFO B，掉电不丢；只有需要改默认值或调参范围时才改 `app_config.h`。校准、暂停、重开、踩陷阱、未收集完撞出口都应分别演示。

## 第五轮：进度与存档

通关一关后按 S1 进入下一关，观察菜单 `PROGRESS` 是否增加；然后**断电重新上电**，重新校准后检查 `PROGRESS` 与 `BEST` 是否保留。若没保留：

- 在 CCS 调试配置里确认没有勾选“擦除信息内存”；若勾选，每次下载都会清空 INFO C/D。
- 暂停后观察 `g_debug.save_ok`：0 表示写入失败，应检查供电与 Flash 操作。
- 不要擦除 INFO A（出厂 TLV/校准数据）。存档设计与风险见 [存档系统说明](save_system.md)。

## 按键复测

1. 先平放板子，S1 按住约 0.1～0.3 秒再松开，检查是否先显示 `HANDS OFF 1 SEC`，再显示 `KEEP STILL`，静置后是否进入菜单。校准中避免再次触碰板子；失败时会显示具体原因与统计值。
2. 进入菜单后，连续短按 S2 10 次，每次间隔约 0.3 秒，确认每次关卡都切换。
3. 再检查 S1 开始、暂停、恢复，以及长按功能。
4. 若仍漏按，下一步分别确认 S1/S2 原始输入电平、机械接触以及中断运行情况。

## 上板校准操作

1. `HANDS OFF 1 SEC`：静置等待 1 秒，暂不计入统计。
2. `KEEP STILL`：样本数从 0 增加到 64。
3. 校准通过进入 `GRAVITY MAZE` 选关菜单。

等待加采样通常至少约 2.3 秒；主循环绘图、SPI 以及实际采样时序会影响总时长，没有实测保证。

校准中重复短按 S1 不会重置进度；长按 S1 取消并返回准备。在校准界面长按 S2 可以提前查看传感器数据（诊断页），S2 短按或长按可返回菜单。

### 失败屏幕如何读取

| 屏幕提示 | 检查结果 | 下一步 |
|---|---|---|
| `TOO MUCH MOTION` | 至少一轴的64次样本最大值减最小值超过120mg | 先静置重试；若平放不动也反复超限，查看诊断数据和传感器型号 |
| `CHECK Z / POSTURE` | Z均值绝对值不在600～1400mg | 确认水平摆放；核对Z轴读数、量程换算和通信 |
| `BOARD NOT FLAT` | Z检查通过，但X或Y均值绝对值超过600mg | 调整摆放；若已平放则核对轴和数据 |

多项同时不通过时优先显示波动、其次Z、最后X/Y倾斜，提示是算法检查结果，不能单独证明硬件故障原因。失败页的 DX、DY、DZ 是各轴最大值减最小值，Z 是Z轴均值，单位都是mg；数字宽度为4位，极端异常值可能只显示末4位，完整值可在 CCS 的 `g_debug` 中读取。

若仍失败，拍下整个失败页面，再长按 S2 约 1 秒进入诊断页，记录 TYPE 及 X/Y/Z 大致数值与跳动范围。正常平放预期 X/Y 接近 0、Z 约 ±1000mg，允许零偏与噪声；在没有数据前不靠扩大阈值强行通过。

## 复测时值得记录的画面

在功能联调阶段，以下记录最有价值：

- 诊断页：板面朝上、翻面朝下各一张完整屏幕（见 [传感器诊断与 Z 轴排查](sensor_diagnostics.md)）；
- 第一关通关页，以及菜单的 `PROGRESS`；
- 断电重新上电后 `PROGRESS/BEST` 是否保留；
- 若无法编译，第一条 error 及其上下文；若出现 `SENSOR ERROR`，错误页全屏。

传感器幅度的已知观测为 X 侧立约 −1008mg、Z 正反面约 ±162mg。如果板子平放在仍停在 `CHECK Z / POSTURE`，属于已知的 Z 幅度问题（见 [已知限制](#已知限制)），不是校准流程错误。

## 已知限制

- **Z 轴幅度偏小**：实物 CMA3000 在板面朝上/朝下时 Z 仅约 ±162mg，而 1g 应约 56 个计数（18mg/count）；校准判据仍是 `|Z| 在 600～1400mg`，因此这样的板子会停在 `CHECK Z / POSTURE`。根因未确定，尚未做任何补偿或放大，排查方法见 [传感器诊断与 Z 轴排查](sensor_diagnostics.md)。
- **未在实物上验证的功能**：TUNE 调试台的滚轮读数/转向与按键手感、LCD 倾角条、INFO B 掉电保持、6 关实际手感与倾角调速、能量点/陷阱/出口锁定图形显示、30 分钟连续运行。主机测试结果见 [验证记录](validation.md)。
- **目标构建尺寸未知**：Flash/RAM 占用与最坏栈使用需查看 CCS 的 map 文件，没有实测数据。
