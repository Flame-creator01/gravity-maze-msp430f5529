# 传感器诊断与 Z 轴排查

本文汇总加速度计读数的已知现象、诊断页用法，以及 Z 轴幅度偏小的排查思路。日常上板步骤见 [首次上板与联调步骤](bringup.md)，引脚与寄存器配置见 [硬件资源与引脚映射](hardware_mapping.md)。

## 目前已经知道什么

实物为 SEEED-EXP430F5529 V1.0，固件识别为 TYPE=1（CMA3000）。现场观测：板面朝上 Z≈+162mg、翻面 Z≈−162mg；侧立时 X≈−1008mg。（早期曾把 X 看成 −108、把翻面 Z 记成仍为 +162，该判断已更正。）Z 会随重力方向变号，但幅度明显偏小，不能称为完全无响应，也未证明器件损坏。

失败页曾显示 DX=54、DY=72、DZ=18mg，Z 均值约 +168mg：这组波动在 120mg 阈值以内，失败主要来自 Z 重力分量检查。无需反复重试校准，也不必把几十 mg 的跳动直接认定为故障。

CMA3000-D01 四页手册第 2 页写明 ±2g/400Hz 时 56count/g，约 17.86mg/count。代码采用 18mg/count，所以 ±162mg 对应约 ±9 个计数，而 1g 通常应为约 56 个计数。统一修改三轴倍率无法解释“X 已接近 1g 而 Z 偏小”的现象；灵敏度误差 ±10% 也不足以单独解释这种幅度差异。当前根因仍需实物诊断。

## 诊断相关实现

- 保留游戏、按键中断扫描、事件队列、1 秒校准等待和全部 Markdown 文档。
- CMA3000 初始化增加 RSTR 复位序列，再检查状态并配置 CTRL=0x94。
- SPI 事务间留约 50us，结束时有界等待 UCBUSY 再释放 CS；发送、接收和忙状态超时均返回错误。
- 采样前检查控制寄存器及 CMA3000 状态校验位，避免配置异常继续作为有效样本。
- 诊断页增加原始计数、版本/身份、控制/状态寄存器、通信与样本有效标志；错误页也显示寄存器快照。
- 诊断页短按 S1 重新初始化：成功回校准，失败显示 `SENSOR ERROR`。

没有放大 Z 值、降低校准门槛或自动忽略 Z。复位与通信改进是否影响实物读数，需下载后确认。

## 建议的复测顺序

1. `CALIBRATE` 页面出现后，先不按 S1，长按 S2 约 1 秒进入诊断。
2. 板面朝上，松开按键与线材，等约 2 秒，拍摄完整屏幕。
3. 翻面朝下，稳定后再拍一张完整屏幕。不要靠按压引脚把板子压平；可用两块等高、绝缘且稳固的支撑托住板边，避开焊点和按键。

若启动直接显示 `SENSOR ERROR`，拍错误页，短按 S1 重试一次并记录结果。记录这两张诊断页即可，无需先完成校准。

## 诊断页字段含义

```text
ACCEL DIAG TYPE1
Ixx C94 Sxx B1
X  +0036  +0002
Y  +0072  +0004
Z  +0162  +0009
MG     RAW COUNTS
S1 REINIT S2 MENU
SAMPLE OK
```

上面仅为格式示例，不是本工程实测值。X/Y/Z 左列单位 mg，右列为有符号原始计数。诊断数据未做游戏轴交换、滤波和偏置扣除。

| 项目 | 含义 |
|---|---|
| TYPE | 1为CMA3000驱动，2为LIS3DH驱动；配置匹配不等于各轴准确 |
| I | 十六进制；CMA3000为REVID版本寄存器，没有硬编码固定正常值；LIS3DH为WHO_AM_I，预期33 |
| C | 十六进制控制寄存器；TYPE1预期94，TYPE2预期47 |
| S | 十六进制状态寄存器；TYPE1的bit0置位会报错，不要求整字节必须00 |
| B | 1表示最近驱动操作未超时，0表示超时；无法证明电气信号和物理数值一定正确 |
| SAMPLE OK | 最近读取返回有效样本；LIS3DH暂无新数据会显示NO NEW SAMPLE |

LIS3DH 的 CTRL_REG4 可在 CCS 观察 `g_debug.accel_diag.ctrl4`，预期 88。原始诊断字段、错误码和其他观察量见 [首次上板与联调步骤](bringup.md#第一轮工程与下载)。失败后原始计数可能保留或部分更新，因此只把 `SAMPLE OK` 时的轴值视为有效采样结果。

诊断页短按 S1 会复位并重新配置传感器，成功后回 `CALIBRATE`，再长按 S2 即可返回诊断；这与仅重新做水平校准不同。S2 短按或长按返回菜单，未校准时仍不能直接进入游戏。

## 根据结果继续定位

若 Z 恢复到约 ±1000mg，再进行正常校准并记录是否稳定。若 Z 仍为约 ±162mg 且原始计数仅约 ±9，说明低幅度已经出现在软件换算之前；仅凭该结果仍不能区分传感器、焊接/供电和通信等原因。结合控制/状态回读，再决定是否需要进一步六面测试或电气排查，不先宣布器件损坏。

对应主机测试已通过 C89 编译，含生产 SPI 驱动的寄存器模型和超时注入；尚未执行 TI 目标编译和实物验证。资料及各自适用范围见 [资料来源与兼容性依据](sources.md)。
