# 图片与截图

仓库自带的实物照片与屏幕截图，供根目录 README 与各主题文档引用。从仓库根目录可用 `docs/images/screenshot-menu.png` 引用，从 `docs/` 下可用 `images/screenshot-menu.png`。

| 文件 | 内容 | 有内容的说明位置 |
|---|---|---|
| `board.jpg` | SEEED-EXP430F5529 V1.0 实物照片，用于确认板卡与丝印。 | [硬件资源与引脚映射](../hardware_mapping.md) |
| `calibration-failure.jpg` | 校准失败页实拍，用于对照 `TOO MUCH MOTION` / `CHECK Z / POSTURE` / `BOARD NOT FLAT` 提示与 DX/DY/DZ 数值。 | [首次上板与联调步骤](../bringup.md) |
| `screenshot-menu.png` | 选关菜单：`LEVEL`、`BEST`、`PROGRESS`、`LOCKED` 与按键提示。 | [游戏玩法与 TUNE 调参](../gameplay.md) |
| `screenshot-play.png` | 游戏中画面：HUD `L/S/K/T`、迷宫、能量点、陷阱与出口。 | [游戏玩法与 TUNE 调参](../gameplay.md) |
| `screenshot-tune.png` | TUNE 灵敏度调试台：参数名、`NOW` 倾角、`INT` 间隔、`DIR` 方向与倾角条。 | [游戏玩法与 TUNE 调参](../gameplay.md) |

`board.jpg` 与 `calibration-failure.jpg` 是实物拍摄；三张 `screenshot-*.png` 由程序帧缓冲（102×64）按面板深底亮字的显示方式渲染，非示意图、非手工绘制。
